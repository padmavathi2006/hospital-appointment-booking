About This Project

The Hospital Appointment Booking System is a full-stack learning project built using HTML, CSS, Bootstrap, JavaScript, Node.js core modules, and AWS DynamoDB. It is designed to feel professional while keeping the code structure simple for students.

Patients can register, log in, browse doctors, book appointments and track their history. Admins can manage doctor records, review all appointments and see important system statistics in one dashboard.

Manual routing with Node.js `http`, `fs` and `url` modules
AWS DynamoDB integration using the JavaScript v3 SDK
Form validation with clear error handling
Admin and patient workflows inside one complete project
